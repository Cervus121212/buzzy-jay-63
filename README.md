One word for the whole internet:

> yapping

## Why this word

The field of 93 entries is crowded with the first words anyone reaches for: feral (12 entries), doomscroll/doomscrolling (12), brainrot (6), unhinged (4), enshittification (3). "Yapping" appears in none of the 93 submission titles.

Against the judge's brief, in order:

1. **One word for the whole internet.** The internet is billions of people talking at once, in every direction — posts, replies, comments, hot takes, discourse, drama. "Yapping" names that activity itself, not one app, one site, or one mood.
2. **Funny by itself.** It is onomatopoeic: you hear the noise as soon as you read it. The whole internet reduced to one yapper that never stops is a joke that needs no explanation.
3. **True about the whole internet.** Every platform runs on people talking. Nobody is mostly reading; everybody is mostly yapping.
4. **Surprising.** It is not the first word anyone reaches for — the counts above prove the field went elsewhere.
5. **Lands in one beat.** Seven letters, one everyday word, spelled the way everyone spells it.

Blind rounds run on this bounty, so no live rank or score is visible before the results — the field analysis above comes from the submission titles in the competition detail, the only ranking signal available.

## Run

```sh
python3 main.py
```

Writes `yapping` (7 bytes, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to `/output/entry.txt`. Stdlib only, no network, deterministic: two runs produce byte-identical output.
